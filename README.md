# Crumb
> "Small dih, big dreams"

## About
Crumb is a UCI chess engine written in C++. The reason it is named "crumb" is because
its skill level is about the same as that of a bread crumb.

## Features
As of the current version, here are all the features:
* Bitboard + mailbox board representation (version 0.1.0)
* Bitboard attackgen (version 0.1.0)
* Bitboard pseudolegal movegen (version 0.1.0)
* Copy-Make move approach (version 0.1.0)
* 3-fold detection (version 0.1.0)
* Perft (verified movegen and move-making validity) (version 0.1.0)
* Search
    * Alpha-beta (version 0.1.0)
    * Iterative deepening (version 0.1.0)
    * Quiescence search (version 0.1.1)
    * Transposition Table (version 0.1.2)
    * Move Ordering (version 0.1.2)
    * Principle Variation Search (version 0.1.3)
    * Reverse Futility Pruning (version 0.1.3)
    * Aspiration Window (version 0.1.3)
* Evaluation
    * PeSTO Evaluation (version 0.1.0)
    * Tempo bonus (version 0.1.0)
